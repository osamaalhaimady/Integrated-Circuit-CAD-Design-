# Integrated Circuit CAD Design

## Overview

This repository contains a collection of integrated circuit and electronic circuit simulations developed as part of the Integrated Circuit CAD Design course at Yangzhou University.

The projects were implemented and analyzed using LTspice and semiconductor technology models, with a focus on transistor-level circuit behavior, CMOS logic, power consumption, and circuit performance.

## Projects

| No. | Project | Main Topics |
|---|---|---|
| 01 | Active Low-Pass Filter | Frequency response, cutoff frequency, transient analysis |
| 02 | NMOS Transistor Characterization | I-V characteristics, operating regions, leakage, body effect |
| 03 | CMOS Inverter Characterization | Voltage transfer characteristics, power, CMOS vs. resistive-load inverter |
| 04 | NAND2 & AND4 Analysis | CMOS logic, power consumption, delay, technology scaling |

## Tools & Technologies

- LTspice
- CMOS Circuit Simulation
- MOSFET Characterization
- 65 nm / 45 nm / 32 nm Technology Models
- DC Analysis
- AC Analysis
- Transient Analysis
- Power and Performance Analysis
